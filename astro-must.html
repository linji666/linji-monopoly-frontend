2. 行星距离（正弦定理）大题必考

sin α / D = sin θ / r = sin γ / d

  • α = 距角（地球—太阳与地球—行星的夹角）
  • θ = 相位角（行星—太阳与行星—地球的夹角）
  • γ = 顶角（太阳处的角）
  • D = 行星到太阳，d = 行星到地球，r = 地球到太阳（1 AU）

sin 有两个解，一定要判断取钝角还是锐角。内行星距角小 → 相位角接近 180°。

3. 活力公式（变轨题）大题必考

v² = GM (2/r − 1/a)

总能量：E = −GMm / 2a

思路：圆轨道先算 v₁，变轨后 v₂ 已知倍数 → 相除求新 a → 再求 e。
e = (a − r) / a

4. 光度与温度 大题必考

L = 4πR²σT⁴

λmax · T = b（b ≈ 2.898×10⁻³ m·K）

看到"光谱峰值在多少 Å" → 先换成 nm → 再除 b。

对比太阳：L/L⊙ = (R/R⊙)² · (T/T⊙)⁴

5. 双星模型 偶尔考

GM = ω² L³

速度、加速度、轨道半径与质量成反比。

6. 望远镜题 必考，送分

放大倍率 → f物/f目；实际视场 = 目镜视场 / 放大倍率；
底片比例尺 → 206265/F；每像素视场 = 像素尺寸 × 底片比例尺（注意 μm→mm）。

移出视场时间：天赤道 15°/h；某纬度天顶恒星速度 = 15° × cos(纬度)。

7. 韦恩 / 星等 / 光度题连招

给光谱图 → 找峰值波长 → 韦恩定律求 T → 求出 L → 用普森公式求绝对星等。
